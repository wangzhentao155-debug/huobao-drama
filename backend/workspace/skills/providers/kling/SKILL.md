# Kling 提示词包

适用于 Kling / 兼容图生视频协议。本包只约束提示词写法，不假设具体 API 字段；实际参数由适配器决定。

## 1. 输入角色

- 有首帧图时，提示词先描述首帧里的人物、场景、构图和光，再写动作如何发展。
- 有尾帧图时，动作必须能自然走到尾帧状态；不要写与尾帧冲突的姿势或位置。
- 无参考图时，先完整交代主体外观、服装、场景和光源，避免模型自由发挥。

## 2. 结构

```text
主体 + 起始状态 + 主动作 + 镜头运动 + 场景/光 + 结束状态
```

- 一个提示词只承载一个连续动作单元；复杂动作拆成多个镜头/任务。
- 动作按时间顺序写，动词具体可见：走、停、转身、抬手、后退、坐下。
- 镜头运动写清方向、速度和起止：固定、缓慢推近、跟随、环绕、拉远。
- 不写“电影感”“大片感”等空泛风格词；风格由项目注入。

## 3. 参考与连续性

- 角色外观、服装、道具必须与参考图一致；状态变化要明确写出。
- 场景光源方向固定；不要在同一镜头里凭空换主光。
- 人物出画/入画方向、视线方向连续。
- 对白只作为口型/表演提示，逐字来自分镜，不新增台词。

## 4. 负向约束

- 不新增人物、不换脸、不换服装、不改变场景结构。
- 不出现多余肢体、手指畸形、道具穿模、人物漂浮。
- 不跨场景、不闪回、不做无依据的镜头切换。
- 不写水印、文字、logo。

## 5. 禁止事项

- 不写 API 参数名、模型版本号或内部字段。
- 不写抽象情绪词；情绪转成表情、呼吸和身体动作。
- 不写画风、滤镜、色调。

## 6. 自检

- [ ] 首帧/尾帧状态与动作不冲突
- [ ] 一个连续动作单元
- [ ] 镜头运动有方向、速度、起止
- [ ] 角色/服装/道具连续
- [ ] 负向约束覆盖换脸、穿模、多余人物
- [ ] 无 API 字段和画风词
