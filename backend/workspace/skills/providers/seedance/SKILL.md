# Seedance 提示词包

适用于火山引擎 Seedance / 兼容协议。本包只约束提示词写法，不假设具体 API 字段；时长、画幅、分辨率由适配器和配置决定。

## 1. 结构

按“主体 + 动作 + 镜头 + 场景/光 + 连续性”组织，每个时间段一个主动作：

```text
出场人物：@角色；场景：@场景。
0-3秒：中景固定，@角色 从门口走入，停在桌边，抬眼看向 @对手。
3-6秒：切到近景，@角色 手指收紧，呼吸变浅。
```

- 首行信息头列出实际出场的角色、场景、道具。
- 按 3 秒分段；时间段连续、无重叠。
- 一个段落不跨场景；段内可切镜，切点对齐分镜子镜头。

## 2. 参考图与首尾帧

- `@角色` / `@场景` / `@道具` 必须与上下文列表完全一致。
- 首帧图用于锁定起始构图；尾帧图用于锁定结束状态；两者同时存在时，动作必须能从首帧走到尾帧。
- 参考图只承担“外观/场景/道具”锚点，不把参考图里的构图强行复制到每个镜头。
- 同一角色跨镜保持脸、发型、服装一致；换装/受伤要写清状态变化。

## 3. 动作与镜头

- 主动作可见、可执行；避免“激烈”“震撼”等抽象词。
- 镜头运动写起止状态和触发点；没有依据的推拉摇移删除。
- 多镜头段落按“建立空间 → 推进动作 → 落到结果/反应”分配时间。
- 对白逐字来自分镜，不新增台词；3 秒念不完的台词拆段。

## 4. 时长与连续性

- 时长、画幅、分辨率按当前配置；不写超出模型能力的时长。
- 同段落内人物位置、视线、屏幕方向连续；段间硬切也要接得上。
- 光源方向、道具状态、服装状态跨段连续。

## 5. 禁止事项

- 不写 API 参数名、模型版本号或服务商内部字段。
- 不跨场景、不闪回、不新增人物/事件/台词。
- 不写画风、滤镜、色调；风格由项目统一注入。
- 不引用列表之外的名字。

## 6. 自检

- [ ] 首行信息头完整
- [ ] 3 秒分段连续
- [ ] @引用与列表一致
- [ ] 首尾帧动作可衔接
- [ ] 对白逐字、不新增
- [ ] 时长/画幅符合配置
- [ ] 无 API 字段和画风词
