# 即梦提示词包

适用于即梦 / 兼容文生视频、图生视频协议。本包只约束提示词写法，不假设具体 API 字段；实际参数由适配器决定。

## 1. 结构

按“主体 + 场景 + 动作 + 镜头 + 光/氛围 + 连续性”组织：

```text
@角色 在 @场景 中，从 [起始状态] 开始，[主动作]，镜头 [运动方式]，
[光源方向与明暗]，[结束状态]。
```

- 先交代谁、在哪、什么状态，再写动作。
- 一个段落一个主动作；复杂动作拆成多个镜头。
- 多镜头段落按 3 秒左右分段，段时间连续。

## 2. 参考图

- 角色参考图锁定脸、发型、服装；场景参考图锁定空间结构和光源；道具参考图锁定外观。
- `@角色` / `@场景` / `@道具` 与上下文列表完全一致。
- 参考图不替代动作描述；动作、接触、结果仍要写清。
- 同一角色跨镜保持外观一致；换装、受伤、淋雨要写状态变化。

## 3. 动作与镜头

- 动词具体可见：走、停、转身、抬手、攥紧、后退、坐下。
- 镜头运动有触发点和起止：推近、拉远、跟随、环绕、固定。
- 景别服务信息：环境用全景，关系用中景，情绪/细节用近景或特写。
- 不写无依据的甩镜、旋转、快速变焦。

## 4. 连续性

- 人物位置、视线、屏幕方向连续；不要段内跳轴。
- 光源方向、道具状态、服装状态跨段连续。
- 对白逐字来自分镜；3 秒念不完的台词拆段。

## 5. 禁止事项

- 不写 API 参数名、模型版本号或内部字段。
- 不新增人物、事件、台词；不改变胜负或结果。
- 不写画风、滤镜、色调；风格由项目注入。
- 不引用列表之外的名字。

## 6. 自检

- [ ] 主体、场景、动作、镜头、光齐全
- [ ] 一个段落一个主动作
- [ ] 参考图角色/场景/道具一致
- [ ] 人物位置、视线、屏幕方向连续
- [ ] 对白逐字、不新增
- [ ] 无 API 字段和画风词
