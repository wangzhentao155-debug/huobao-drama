# LibTV 提示词包

适用于 LibTV / MCP 兼容视频生成工具。本包只约束提示词和工具调用前的描述，不假设具体 API 字段；实际参数由适配器/MCP 工具定义决定。

## 1. 工具调用边界

- 只调用当前 MCP 工具暴露的参数；不猜测未声明的字段。
- 工具调用前先确认：主体、场景、参考图、时长、画幅是否齐全；缺失时返回阻塞原因，不硬生成。
- 提示词与工具参数分开：提示词写画面和动作，工具参数写模型配置。

## 2. 提示词结构

```text
主体 + 场景 + 起始状态 + 主动作 + 镜头运动 + 光源/氛围 + 结束状态
```

- 首行交代出场角色和场景，使用 `@角色` / `@场景` / `@道具` 引用。
- 一个镜头一个主动作；动作有起止和可见结果。
- 镜头运动写方向、速度和起止；没有触发点的运动删除。
- 光源方向、明暗重点写清；不从参考图之外发明主光。

## 3. 参考与连续性

- 参考图只承担外观/场景/道具锚点；不强行复制参考图构图。
- 角色外观、服装、道具状态跨镜连续；变化要有上游依据。
- 人物位置、视线、屏幕方向连续；段间硬切也要接得上。
- 对白逐字来自分镜，不新增台词。

## 4. 失败与重试

- 工具返回参数错误时，只修参数，不改写上游事实。
- 工具返回内容审核/能力不支持时，返回明确原因，不反复重试同一请求。
- 不把一次失败的结果当作已生成产物继续下游。

## 5. 禁止事项

- 不写未声明的 MCP 工具字段或模型版本号。
- 不新增人物、事件、台词；不改变结果。
- 不写画风、滤镜、色调；风格由项目注入。
- 不跨场景、不闪回。

## 6. 自检

- [ ] 只使用已声明的工具参数
- [ ] 主体/场景/参考/时长/画幅齐全
- [ ] 一个镜头一个主动作
- [ ] 参考与状态连续
- [ ] 失败返回结构化原因，不反复重试
- [ ] 无未声明字段和画风词
