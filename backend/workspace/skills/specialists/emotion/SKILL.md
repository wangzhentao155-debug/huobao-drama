# 情绪与微表演（专项）

仅在内容标记 `emotion` 命中时加载。目标是把情绪转成可拍摄、可表演的可见行为，而不是抽象情绪词。

## 1. 情绪转折

- 每个情绪单元先确定：之前相信什么、发生了什么、之后怎么变。
- 转折必须落在具体事件或台词上，不靠旁白解释。
- 一段只承载一个主要情绪转折；多个转折拆到不同段落。

## 2. 可见表演

按以下层级写，不要只写“难过/生气”：

- 微表情：眼神、眉、嘴角、下颌、眨眼频率。
- 呼吸：变浅、屏住、叹气、吸气后的停顿。
- 身体行为：肩膀垮下、手指攥紧、后退半步、转身避开视线。
- 声音：语速、音量、停顿、尾音、欲言又止。
- 潜台词：说出口的话和真实意图之间的落差。

## 3. 节奏与连续性

- 情绪爆发前留一个停顿或动作准备；爆发后给一个反应镜头。
- 同一场景内情绪强度连续变化，不突然跳变。
- 角色习惯性小动作要跨镜保留；状态变化（哭过、受伤、淋雨）要连续。
- 台词情绪与动作一致；不要让角色嘴上说没事、身体却毫无反应。

## 4. 禁止事项

- 不写“他很伤心”“气氛很压抑”这类抽象标签。
- 不写夸张嚎哭、摔东西等与人物设定不符的过度表演。
- 不用旁白替角色解释情绪。
- 不新增事件或改变台词含义。

## 5. 自检

- [ ] 情绪转折有事件依据
- [ ] 微表情、呼吸、身体行为至少各有一项
- [ ] 潜台词清楚，不是解释性台词
- [ ] 情绪强度连续，没有跳变
- [ ] 没有抽象情绪词和过度表演
