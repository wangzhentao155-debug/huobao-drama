# 特效与图层（专项）

仅在内容标记 `fx` 命中时加载。目标是把特效写成可执行的时间与图层描述，而不是“加点光效”。

## 1. 特效单元

每个特效写清：

- 触发：由什么动作、台词、道具或环境事件触发。
- 出现位置：画面哪个区域、相对人物/道具的位置。
- 图层：前景、中景、背景；在人物前还是人物后。
- 遮挡关系：哪些人物、道具或场景元素会遮住特效，或被打亮。
- 结束条件：消散、熄灭、被挡住、随动作离开画面。
- 可见结果：照亮谁、改变什么状态、留下什么痕迹。

## 2. 与画面元素交互

- 特效必须和场景固有光源、人物动作、道具状态发生关系，不能悬浮在画面外。
- 法术/能量/烟雾/火焰等要有明确边界和持续时间。
- 口型类效果注明对应角色与台词段落；不要和旁白混淆。
- 特效不能替代动作结果；该发生的位移、受伤、道具变化仍要写清。

## 3. 连续性

- 同一特效跨镜保留颜色逻辑、强度变化和残留痕迹；但不写具体画风词。
- 特效消失后，人物服装、道具、场景的状态要接得上。
- 多个特效同屏时，写清主次和遮挡顺序。

## 4. 禁止事项

- 不新增事件、人物或改变胜负。
- 不写“炫酷”“电影级光效”这类无法执行的词。
- 不写画风、滤镜、色调；风格由项目统一注入。
- 不用特效掩盖动作或空间错误。

## 5. 自检

- [ ] 每个特效有触发、位置、图层、遮挡、结束条件
- [ ] 特效与人物/道具/场景有交互
- [ ] 口型类效果注明对象
- [ ] 特效消失后状态连续
- [ ] 没有新增事件和画风词
