# 动作编排与接触（专项）

仅在内容标记 `action` 命中时加载。目标是把“打斗/追逐/冲突”写成观众能看清因果的动作链，而不是抽象描述。

## 1. 动作链

每个动作单元按顺序写清：

- 起势：谁先动、为什么动、从什么姿态开始。
- 接触点：手、脚、肩、武器或道具的接触位置。
- 力传递：谁推谁、往哪个方向、力量如何改变对方姿态。
- 可见结果：位移、跌倒、后退、格挡、道具脱手或损坏。
- 反应：被击中、被挡住、躲开之后，人物的下一步动作和表情。

## 2. 镜头可读性

- 关键接触和结果必须落在画面内；不要把决定性动作放在画外。
- 每个动作段落至少一个镜头能看清“谁对谁做了什么、结果是什么”。
- 保持轴线、视线和屏幕方向连续；人物换位要有可见过程。
- 动作速度变化要写出来：蓄力、爆发、停顿、失衡、恢复。

## 3. 道具与环境

- 武器/道具的持有手、状态和位置必须连续；脱手、损坏、换手要写清。
- 利用场景锚点：墙面、桌角、门框、楼梯、地面湿滑等，动作要遵守空间关系。
- 不凭空增加武器、道具或环境机关。

## 4. 禁止事项

- 不新增事件、人物、招式或胜负结果。
- 不写“激烈打斗”“眼花缭乱”这类无法执行的抽象词。
- 不写画风、镜头滤镜或特效风格；特效由 `fx` 专项负责。
- 不让角色做出超出体型、年龄和场景条件的动作。

## 5. 自检

- [ ] 每个动作有起势、接触、力传递、可见结果
- [ ] 关键接触在画面内
- [ ] 轴线与屏幕方向连续
- [ ] 武器/道具状态连续
- [ ] 没有新增事件或胜负
- [ ] 没有抽象动作词和画风词
